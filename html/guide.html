Repair Guides

Common Windows blue screen issues and how to fix them.

Use this guide to identify the error code and solve the problem.

BSOD 0x0000007B

Error code: 0x7B

This usually points to a storage or hard drive connection problem. Check that the drive is connected properly and try Safe Mode.

  • Reconnect the storage drive
  • Run startup repair
  • Check BIOS settings

BSOD 0x0000001A

Error code: 0x1A

This is often related to memory or faulty drivers. Start by removing recently installed hardware and updating drivers.

  • Update graphics and chipset drivers
  • Remove and test RAM modules one by one
  • Revert recent updates

BSOD 0x00000050

Error code: 0x50

This commonly appears after a bad driver or a corrupted system file. Restore the system or run SFC.

  • Run System File Checker
  • Boot into Safe Mode
  • Uninstall the last problematic driver

BSOD 0x000000D1

Error code: 0xD1

This can be caused by outdated or incompatible drivers. Update drivers and check if the problem started after recent changes.

  • Check device drivers
  • Disable newly installed software
  • Use Windows Update

BSOD 0x000000F4

Error code: 0xF4

This stop error often points to a problem with the hard drive or its connection. It can also be related to RAM issues or corrupted system files.

  • Check disk health and cables
  • Scan for malware
  • Run system file checker

BSOD 0x0000000A

Error code: 0x0A

This error happens when a driver or program tries to access memory incorrectly. It is often caused by an outdated driver or an incompatible antivirus.

  • Update recent device drivers
  • Temporarily disable third-party antivirus
  • Test your RAM with Windows Memory Diagnostic

BSOD 0x0000003B

Error code: 0x3B

This is frequently caused by graphics card issues or corrupted system files. Updating your display driver is the best place to start.

  • Update your graphics card driver
  • Run System File Checker (SFC)
  • Uninstall recently added programs

BSOD 0x0000007E

Error code: 0x7E

This error often occurs right after updating Windows or adding new hardware that is not fully compatible with your computer.

  • Check Device Manager for warning symbols
  • Update your computer motherboard BIOS
  • Boot into Safe Mode to undo recent updates

BSOD 0x0000009F

Error code: 0x9F

This happens when a part of your computer freezes while going to sleep or waking up. Disabling Fast Startup often fixes it.

  • Turn off Fast Startup in Power settings
  • Update Wi-Fi and Bluetooth drivers
  • Disconnect external USB devices before sleep

BSOD 0x00000116

Error code: 0x116

This error means your screen or graphics card stopped responding. It is commonly solved by reinstalling your graphics driver or cleaning dust from fans.

  • Reinstall graphics card drivers
  • Clean dust from computer fans and vents
  • Reset graphics card settings to default

BSOD 0x00000124

Error code: 0x124

This indicates a physical hardware issue, most often caused by an overheating processor, loose parts, or power supply issues.

  • Make sure the computer is not overheating
  • Check that all internal parts are firmly connected
  • Reset BIOS settings to factory defaults

BSOD 0x00000133

Error code: 0x133

This usually occurs when your storage drive or SSD takes too long to respond. Updating your SSD software or drive drivers usually solves this.

  • Update your SSD firmware using the maker's app
  • Install the latest Windows updates
  • Check the hard drive for errors

BSOD 0x00000139

Error code: 0x139

This error is often triggered by game anti-cheat software, failing memory, or corrupted system files.

  • Update or reinstall game anti-cheat software
  • Test your RAM memory for errors
  • Uninstall recent updates if the issue just started

BSOD 0x00000024

Error code: 0x24

This error points to a file system issue on your hard drive or SSD. Running a disk check can find and repair damaged areas.

  • Run disk check (chkdsk) to repair disk errors
  • Check hard drive cables and connections
  • Back up your files in case the drive is failing

BSOD 0xC000021A

Error code: 0xC000021A

This happens when an essential Windows process stops working. Startup Repair or System Restore can usually get your system running again.

  • Run Startup Repair from the recovery screen
  • Use System Restore to go back to an earlier date
  • Boot into Safe Mode to undo recent changes
